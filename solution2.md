In this assignment, I set up the complete web development environment on my computer. First, I installed Visual Studio Code, which is a popular and powerful code editor for web development. Then I installed the LTS version of Node.js to run JavaScript outside the browser and to use npm for managing packages. After that, I installed two important extensions in VS Code — Live Server, which allows me to run my HTML file live in the browser with auto-reload, and Prettier, which automatically formats my code.Next, I created a folder named web-development-practice and created three files inside it: index.html, style.css, and script.js. I wrote the basic structure in the HTML file, added some styling in the CSS file, and added interactivity in the JavaScript file. Then I ran the HTML file using Live Server and saw the output successfully in the browser. Finally, I verified the installation by running node -v and npm -v commands in the terminal, which showed the installed versions. With this, my web development environment was successfully set up and ready to use.
